# LumaPad 安裝與使用教學（繁體中文）

[下載最新版](https://github.com/DeifiedXE/lumapad-android/releases/latest) ·
[English guide](USER_GUIDE.md) · [回到首頁](../README.md)

LumaPad 是以 Moonlight Android 為基礎的非官方客戶端，專門改善不支援手把遊戲的手機
觸控操作。它沿用 Moonlight 的串流連線方式，直接連線 Sunshine，不需要安裝額外的
LumaPad Windows 程式。

## 一、安裝前準備

你需要：

- 一台可執行遊戲與 Sunshine 的電腦。
- 一台 Android 5.0 或更新版本的手機或平板。
- 建議先讓電腦與 Android 裝置連接同一個區域網路；電腦使用有線網路通常最穩定。

如果原版 Moonlight 已經能連上你的電腦，可以直接跳到「安裝 LumaPad」。

## 二、在電腦安裝 Sunshine

1. 前往 [Sunshine 官方 Releases](https://github.com/LizardByte/Sunshine/releases)，下載適合
   電腦系統的穩定版。Windows 一般選擇 AMD64/x64 的 `.msi` 安裝程式。
2. 完成安裝並啟動 Sunshine。Windows 安裝版預設會以背景服務執行。
3. 在電腦瀏覽器開啟 `https://localhost:47990`。
4. 第一次使用時建立 Sunshine 的管理帳號與密碼。瀏覽器可能提示自簽憑證警告；確認網址
   是本機的 `localhost:47990` 後再繼續。
5. 若需要，可在 Sunshine 的 **Applications** 頁面新增遊戲；直接串流桌面也可以使用
   LumaPad 的所有手動配置功能。

完整且最新的主機設定說明請參考
[Sunshine Getting Started](https://docs.lizardbyte.dev/projects/sunshine/latest/md_docs_2getting__started.html)。

## 三、在 Android 安裝 LumaPad

1. 開啟 [LumaPad Releases](https://github.com/DeifiedXE/lumapad-android/releases/latest)。
2. 在最新版本的 **Assets** 下載檔名以 `LumaPad-` 開頭、以 `.apk` 結尾的檔案。
3. 點開下載的 APK。若 Android 阻擋安裝，依提示允許目前使用的瀏覽器或檔案管理器
   「安裝未知應用程式」。不同品牌手機的選單名稱可能略有不同。
4. 返回安裝畫面並按下**安裝**。Google Play 安全防護若詢問是否掃描，可以選擇掃描後繼續。

LumaPad 使用自己的應用程式識別碼，可以和 Google Play 版的原版 Moonlight 同時安裝。

更新 LumaPad 時可直接安裝新版 APK 覆蓋舊版，按鍵配置會保留。若先解除安裝，Android
會一併刪除 LumaPad 的本機設定與所有配置。

## 四、連線與配對 Sunshine

1. 確認電腦上的 Sunshine 正在執行，然後開啟 LumaPad。
2. LumaPad 通常會自動找到同一網路內的電腦。若沒有找到，使用新增電腦功能並輸入電腦的
   區域網路 IP 位址。
3. 點選電腦圖示，LumaPad 會顯示配對 PIN。
4. 在電腦開啟 Sunshine 網頁介面 `https://localhost:47990`，進入 **PIN** 頁面，輸入手機
   顯示的 PIN 與裝置名稱。
5. 配對成功後，在 LumaPad 選擇 **Desktop** 或 Sunshine 中設定的遊戲開始串流。

## 五、啟用鍵盤與滑鼠混合控制

在 LumaPad 主畫面開啟：

**設定 > 螢幕控制按鈕設定 > 顯示螢幕控制按鈕**

接著把**觸控輸入類型**設成：

**鍵盤＋滑鼠（混合搖桿）**

預設版面包含：

- 左側搖桿：W、A、S、D 鍵盤移動。
- 右側透明瞄準區：滑動時輸出相對滑鼠移動。
- 圓形快捷鍵：滑鼠左右鍵、Q/W/E/R 與數字 1–5。
- 輻射快捷輪盤：收納較少使用的鍵盤或滑鼠輸入。
- 串流螢幕切換按鈕：預設在螢幕 1 與 2 之間切換。
- 沒有被控制元件覆蓋的畫面：可用按鈕切換滑鼠／射擊模式及各自的操作設定。

## 六、移動、縮放與設定控制元件

串流畫面左上角的齒輪會依序切換四種模式：

1. **使用模式**：正常遊玩。
2. **移動模式**：拖曳控制元件改變位置。
3. **縮放模式**：拖曳控制元件改變大小。
4. **按鍵綁定模式**：點選按鍵、搖桿、瞄準區或輪盤進行設定；左上角也會出現 `＋`。

再按一次齒輪會回到使用模式並儲存版面。設定過程中出現不同顏色的外框屬正常現象。

### 新增或刪除元件

進入**按鍵綁定模式**後按下 `＋`，可新增：

- 一般虛擬按鍵
- 輻射快捷輪盤
- 滑鼠／射擊模式切換
- 鍵盤移動搖桿
- 自由滑動瞄準區
- 串流螢幕切換按鈕

在按鍵綁定模式點選既有元件，設定視窗內會提供刪除選項。鍵盤搖桿和瞄準區也可以刪除後
再從 `＋` 選單加回來。

## 七、設定按鍵與組合鍵

1. 進入**按鍵綁定模式**。
2. 點選一顆圓形虛擬按鍵。
3. 在鍵盤畫面選擇一個或多個輸入，例如 `L Ctrl + L Shift + Q`，然後儲存。

滿版鍵盤包含功能鍵、方向鍵、數字鍵盤、滑鼠按鍵，以及左右分開的 Ctrl、Shift、Alt 和
Windows 鍵。若偏好原本的清單介面，可到：

**設定 > 螢幕控制按鈕設定 > 按鍵映射介面 > 原本的清單式選擇器**

兩種介面都支援完整按鍵與組合鍵。

## 八、設定瞄準區

在按鍵綁定模式點選右側瞄準區，可以調整：

- 水平與垂直滑鼠靈敏度
- X 軸或 Y 軸反轉
- 觸碰瞄準區期間持續按住的按鍵或組合鍵

需要按住右鍵才會瞄準的遊戲，可把觸碰時按住的輸入設成 **RMB**。這樣手指碰到瞄準區
就會按住滑鼠右鍵，同時滑動控制視角；放開手指時右鍵也會放開。

### 空白區域的滑鼠／射擊模式切換

串流畫面上的**滑鼠／射擊**按鈕會顯示目前模式，點一下即可切換。進入按鍵綁定模式後
點選這顆按鈕，可以分別設定：

- **滑鼠模式**的空白區域靈敏度，以及是否允許左鍵點擊與長按拖曳。
- **射擊模式**的空白區域靈敏度，以及是否允許左鍵點擊與長按拖曳。
- 切換時同時送出的按鍵或組合鍵；可留空。

例如在射擊模式時把切換按鍵綁定為 `Tab`，按一下就會送出 Tab 開啟背包並切到滑鼠模式；
再按一次則送出 Tab 關閉背包並切回射擊模式。兩個模式的靈敏度範圍都是 25%–300%。

左鍵選項只影響未被控制元件覆蓋的空白串流區域，不會影響獨立的虛擬左鍵、瞄準區靈敏度
或雙指捲動。此功能需開啟「將觸控式螢幕作為觸控板使用」。若刪除切換按鈕，可從
`＋ > 滑鼠／射擊模式切換` 加回。

## 九、使用輻射快捷輪盤

輪盤適合收納背包、地圖、技能頁或功能鍵等不常按的操作：

1. 進入按鍵綁定模式，按 `＋ > 輻射快捷輪盤`。
2. 點選輪盤，將扇區數量設為 2–12 個。
3. 點選各扇區，綁定一個按鍵、滑鼠鍵或組合鍵。扇區從正上方開始順時針排列。
4. 回到使用模式後，按住輪盤中心、往目標扇區滑動，放開即可觸發。
5. 滑回中心死區再放開，會取消本次選擇。

每個輪盤可獨立調整：

- **中心死區**：中央取消區的大小。
- **扇區切換遲滯**：減少手指停在邊界時反覆跳格；數值越高越穩定，但切換方向需要滑得
  更明確。
- **選中震動回饋**：選中不同扇區時震動一下。此功能也需要全域的螢幕控制震動設定開啟。
- **觸發模式**：預設為放開手指時點按一次；也可改成選中後持續按住，直到手指放開。

## 十、手動切換控制配置

LumaPad 不再依照 Sunshine 回報的 Steam 或 Desktop 名稱自動切換配置。串流畫面左上角、
齒輪旁會顯示目前的配置名稱，點擊後可以：

- 手動切換配置
- 新增配置
- 重新命名目前配置
- 刪除目前配置

新配置會先複製目前的完整控制版面，之後可再針對 PoE、射擊遊戲或其他遊戲修改。手動選定
的配置會在下次串流時繼續使用，不會因為開啟 Steam 或 Desktop 而被換掉。舊版依應用程式
儲存的 Steam／Desktop 配置，首次遇到時會匯入成命名配置。

## 十一、切換雙螢幕

點一下螢幕切換按鈕，會使用 Sunshine 的 `Ctrl + Alt + Shift + F1` 至 `F12` 快捷鍵切換
串流來源。預設在螢幕 1 與螢幕 2 之間切換。

若順序不符，進入按鍵綁定模式並點選螢幕切換按鈕，修改兩個螢幕編號。實際編號由
Sunshine 的顯示器順序決定。如果現有舊配置沒有此按鈕，可從 `＋ > 切換串流螢幕` 加回。

## 十二、常見問題

### 找不到電腦

- 確認 Sunshine 正在執行，而且手機與電腦位於同一區域網路。
- 在 LumaPad 手動加入電腦的區域網路 IP。
- 檢查 Windows 防火牆或第三方防火牆是否封鎖 Sunshine。

### 有畫面但虛擬按鍵沒有出現

- 確認已開啟「顯示螢幕控制」。
- 確認輸入模式為「鍵盤＋滑鼠（混合搖桿）」。
- 若曾暫時隱藏控制元件，重新開啟螢幕控制顯示。

### 轉盤沒有震動

- 確認輪盤本身的「選中震動回饋」已開啟。
- 確認 LumaPad 的全域螢幕控制震動選項已開啟。
- 部分裝置、省電模式或系統觸覺設定可能會限制震動。

### 更新後配置不見了

正常覆蓋安裝會保留配置；解除安裝會清除資料。新版會把遇到的舊式 Steam／Desktop 版面
匯入為命名配置，請點擊左上角的配置名稱查看。

## 安全性與專案聲明

只從本專案的 [GitHub Releases](https://github.com/DeifiedXE/lumapad-android/releases/latest)
下載 APK。LumaPad 是非官方 Moonlight 衍生專案，不隸屬於 Moonlight 或 Sunshine。
